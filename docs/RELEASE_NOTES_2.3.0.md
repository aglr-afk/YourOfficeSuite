## YourOfficeSuite 2.3.0

A free desktop office suite for Windows: documents, spreadsheets, presentations and 15 PDF tools, working offline on files in your OneDrive folder.

### Install

1. Download `YourOfficeSuite-Setup-2.3.0.exe` below.
2. Run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the setup. No administrator rights are needed, and it installs over any earlier version.

Needs Windows 10 or 11 (64-bit) and about 900 MB of disk space.

### New in this version

- The app now tells you when a new version is out
- One-click install: the update is downloaded, checked and started for you
- "What is new" link on the update bar
- A switch in About to turn the automatic check off
- The updates folder still works for offline use
