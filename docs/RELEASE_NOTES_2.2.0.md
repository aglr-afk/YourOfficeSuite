## YourOfficeSuite 2.2.0

A free desktop office suite for Windows: documents, spreadsheets, presentations and 15 PDF tools, working offline on files in your OneDrive folder.

### Install

1. Download `YourOfficeSuite-Setup-2.2.0.exe` below.
2. Run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The installer is not code-signed.
3. Follow the setup. No administrator rights are needed.

Needs Windows 10 or 11 (64-bit) and about 900 MB of disk space.

### New in this version

- Reopens the tabs you had last time
- Search by file name across all locations
- Right-click menu on files: open, pin, rename, copy, send to PDF Bench
- Pin files and folders to Home
- Light and dark themes
- "Replace the original file" option in PDF tools
- Protect a PDF with a password, and Unlock
- Folder-based update check
- More keyboard shortcuts (press F1 for the list)

### Please note

This is a beta. It passes a 71-check automated suite on a Linux build of the same code, but the installer has not been verified by an automated run on real Windows. Keep backups of important files. See the README for known limits.
