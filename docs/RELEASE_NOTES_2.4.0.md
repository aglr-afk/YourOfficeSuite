## YourOfficeSuite 2.4.0

A free desktop office suite for Windows and macOS: documents, spreadsheets, presentations and 22 PDF tools, working offline on files in your OneDrive folder.

### Install on Windows

1. Download `YourOfficeSuite-Setup-2.4.0.exe` below.
2. Run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the setup. No administrator rights are needed, and it installs over any earlier version.

Already on 2.3.0? The app shows an update bar on Home. Press **Install**.

Needs Windows 10 or 11 (64-bit) and about 900 MB of disk space.

### Install on macOS

1. Download the zip for your Mac below: `YourOfficeSuite-2.4.0-mac-arm64.zip` for Apple Silicon (M1 and newer), `YourOfficeSuite-2.4.0-mac-x64.zip` for Intel.
2. Double-click the zip, then drag **YourOfficeSuite** into **Applications**.
3. Open **Terminal** and run this once, so macOS lets an app from outside the App Store open:

   ```bash
   xattr -cr /Applications/YourOfficeSuite.app
   ```

4. Open YourOfficeSuite.

Needs macOS 11 or newer and about 900 MB of disk space.

### New in this version

- PDF Bench now has 22 tools, all working offline
- Redact PDF: black out names, numbers, emails and phone numbers for good
- Compare PDF: see every word added or removed between two versions
- PDF to Text: save the text, or every image inside a PDF
- Crop PDF: trim margins or change the page size
- Flatten PDF: lock forms, comments and text in place
- Black & white PDF: turn colour pages grey to save ink
- HEIC to PDF: iPhone photos now work in Images to PDF
- Edit and annotate: ticks, crosses, signatures, a form field list and form locking
- File details: shows and removes AI labels from JPG and PNG pictures
