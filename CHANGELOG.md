# Changelog

## 2.3.0

- Online updates: the app checks this project's GitHub releases at start and shows what is new.
- One-click install: the setup is downloaded, checked against its SHA-256 fingerprint and started for you.
- "What is new" link to the release page, and a switch in About to turn the automatic check off.
- The folder-based update check stays available for offline use.
- macOS apps for Apple Silicon and Intel: Mac menu bar, Cmd shortcuts, OneDrive folder detection, opening files from Finder.

## 2.2.0

- Session restore: the tabs you had open come back at the next start.
- Search by file name across all locations.
- Right-click menu on files and folders: open, pin, rename, copy, show in folder, send to PDF Bench.
- Pin files and folders to Home.
- Light and dark theme switch; the editors follow.
- "Replace the original file" option in compress, organise, watermark, page numbers, sign and file details.
- New PDF Bench tools: Protect with a password (AES-256) and Unlock.
- Folder-based update check.
- More keyboard shortcuts and a shortcut list (F1).
- Fixed: the built-in spelling checker tried to download dictionaries from the internet. It is now off.
- Fixed: Escape did not close a menu or window while the keyboard was inside an editor.
- Fixed: an editor loading in the background could take keyboard focus away from Home.
- Fixed: opening a pinned folder could show the previous folder's files.

## 2.1.0

- New PDF Bench tool: File details (metadata) for PDF, Word, Excel, PowerPoint, JPG and PNG.

## 2.0.0

- Renamed to YourOfficeSuite with its own visual identity.
- New Home with Files, Templates and PDF Bench sections.
- 13 starter templates.
- PDF Bench with 12 tools; PDFs open in the editor.

## 1.0.0

- First build: Word, Excel and PowerPoint editing in tabs on files in the local OneDrive folder, autosave, sync-conflict handling and a Windows installer.
